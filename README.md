## Project Goal

Cognify Journal aims to help users capture their thoughts in a structured and organized format using AI assistance.

The AI component is designed to organize, structure, and categorize journal content while intentionally avoiding advice, therapy, emotional labeling, or medical and psychological diagnoses.

## Architecture

* **Architecture Style:** Modular Monolith
* **Packaging Strategy:** Feature-based Packaging

## Tech Stack

* Java
* Spring Boot
* Spring Data JPA

## Engineering Goals

This project is being developed to follow real-world backend engineering practices, including:

* Clean architecture principles
* Separation of concerns
* Feature-based modular design
* Scalable project structure
* Maintainable and testable codebase
* Production-oriented development practices
